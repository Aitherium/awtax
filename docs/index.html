awtax

Turn any tax PDF -- returns, W-2, 1099, statements, even scans -- into structured data you can check.

The problem

Your own tax data gets locked inside one vendor's encrypted format, and a filed return or a mailed W-2 is a PDF nobody's code can read -- half of them are scans with no text at all. Getting your own numbers back out means re-typing them or re-buying the app that sealed them.

instead of trusting
a closed tax app's sealed file you can never read again
you check
a plain, provider-neutral schema of every figure, with the page it came from

Adopt it

git clone https://github.com/Aitherium/awtax

Point it at a tax PDF and get every figure out as structured JSON, scanned forms included.
